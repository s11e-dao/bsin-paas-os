🔗 连接建立流程：

1. 应用启动 → 读取 application.yml 配置
2. Spring Boot 自动配置 → 创建 RocketMQTemplate
3. RocketMQTemplate → 创建 DefaultMQProducer/Consumer
4. 设置 NameServer 地址 → 连接到 NameServer (127.0.0.1:9876)
5. NameServer → 返回 Broker 路由信息
6. 客户端 → 建立到 Broker 的连接 (127.0.0.1:10911)
7. 连接建立完成 → 可以发送/接收消息

📋 关键配置点：

• NameServer 地址配置 (最重要)
  - waas-server: 172.24.0.2:9876
  - app-agent: ${BSIN_ROCKETMQ_NAME_SERVER}
  - brms-server: 127.0.0.1:9876

• 生产者组配置
  - springboot_producer_group
  - test_producer_group

• 消费者组配置
  - consumer_group
  - test_consumer_group

• 超时和重试配置
  - sendMessageTimeout: 10000
  - retryTimesWhenSendFailed: 2

🔧 连接验证方法：

1. Docker 容器状态检查
   docker ps | grep rocketmq

2. NameServer 连接测试
   docker exec rmqnamesrv sh mqadmin clusterList -n localhost:9876

3. Topic 状态检查
   docker exec rmqbroker sh mqadmin topicStatus -n localhost:9876 -t waas-test

4. 代码连接测试
   SimpleRocketMQTest.testRocketMQConnection()

🚨 常见问题：

• 连接失败 → 检查 NameServer 地址和端口
• 超时问题 → 增加 sendMessageTimeout
• 权限问题 → 检查 access-key 和 secret-key
• 网络问题 → 检查防火墙和 Docker 网络配置
